# John Kenneth Lacorte - Portfolio Website

A modern, responsive portfolio website built with HTML, CSS, and JavaScript. Features a dark theme with blue accents, perfect for showcasing software development projects and experience.

## 🚀 Features

- **Responsive Design**: Works perfectly on desktop, tablet, and mobile devices
- **Dark Theme**: Professional dark color scheme with blue accents
- **Smooth Animations**: Scroll animations and hover effects
- **Interactive Navigation**: Mobile-friendly navigation with smooth scrolling
- **Contact Form**: Functional contact form with validation
- **Project Showcase**: Beautiful project cards with technology tags
- **Experience Timeline**: Visual timeline for work experience
- **Certificates Section**: Display of professional certifications
- **Skills Section**: Organized technical skills display

## 📁 File Structure

```
portfolio/
├── index.html          # Main HTML file
├── styles.css          # CSS styles and responsive design

```

## 🎨 Customization Guide

### Personal Information
Edit the following sections in `index.html`:

1. **Hero Section** (Lines 60-75):
   - Update name and title
   - Modify description text
   - Change profile image (replace the icon with your photo)

2. **About Section** (Lines 85-130):
   - Update personal description
   - Modify skills and technologies
   - Add or remove skill categories

3. **Projects Section** (Lines 140-220):
   - Replace project examples with your actual projects
   - Update project descriptions and technologies
   - Add links to GitHub repositories and live demos

4. **Experience Section** (Lines 230-290):
   - Update work experience details
   - Modify company names and dates
   - Customize job descriptions

5. **Certificates Section** (Lines 300-370):
   - Replace with your actual certificates
   - Update certificate names and dates
   - Add relevant icons

6. **Contact Section** (Lines 380-450):
   - Update contact information
   - Add your social media links
   - Modify email and phone number

### Colors and Styling
The color scheme is defined in `styles.css`:

- **Primary Blue**: `#3b82f6`
- **Dark Blue**: `#1d4ed8`
- **Background**: `#0a0a0a`
- **Secondary Background**: `#0f172a`
- **Card Background**: `#1a1a1a`
- **Text Colors**: `#ffffff`, `#cbd5e1`, `#94a3b8`

### Adding Your Photo
1. Replace the profile placeholder in the hero section
2. Add your image to the project folder
3. Update the HTML to use your image instead of the icon

## 🚀 Getting Started

1. **Download/Clone** the project files
2. **Customize** the content in `index.html`
3. **Update** your personal information and projects
4. **Modify** colors in `styles.css` if desired
5. **Test** the website locally by opening `index.html` in a browser
6. **Deploy** to your preferred hosting service
